Field and transmission loss

Kraken.acoustic_field — Method
acoustic_field(sol, ranges, zs, zr; nmodes=length(sol.kr), mode=:coherent)

The complex acoustic pressure field of the normal-mode solution sol for a point source at depth zs, on the grid of ranges (metres) and receiver depths zr (metres).

Returns a length(zr) × length(ranges) matrix (depth down the rows, range across the columns) always, including when ranges or zr is a single number. transmission_loss is the same field in dB.

Arguments

  • sol: the solution from kraken_jl.
  • ranges: a range or a vector of ranges (m), all positive.
  • zs: source depth (m, positive downwards).
  • zr: a receiver depth or a vector of them (m).

Keyword arguments

  • nmodes: how many modes to sum, from the first (largest kᵣ). Defaults to all of them; the solution has already discarded everything that is not propagating.
  • mode: :coherent or :incoherent, matching field.exe's .flp task codes C (or blank) and I. A coherent sum adds the modes as complex amplitudes and so shows the interference structure: the nulls a real receiver sees at one frequency. An incoherent sum adds their intensities, √(Σ|term|²), which discards the phase and leaves the smooth mean level, for when the interference pattern is unresolved, unknown, or about to be averaged away. :semicoherent is not offered; asking for it raises an error that explains why.

Conventions

The phase convention is KRAKEN's exp(i(ωt - kᵣr)), and the amplitude is normalized to the pressure of a point source at 1 m, so field.exe's output can be compared without rescaling. Take conj for the exp(-iωt) convention used in Jensen et al. See the comments at the top of kraken_field.jl for where each factor comes from.

An incoherent field has thrown its phase away by construction, so what comes back is a magnitude carried in a complex number for a uniform return type: real, non-negative, and not a pressure that can be added to another field. Only :coherent returns a complex pressure with its phase.

The field is the far-field mode sum, which is singular at r = 0 and inaccurate within a wavelength or so of the source; zero and negative ranges are rejected rather than returned as Inf.

Example

julia> sol = kraken_jl(UnderwaterEnv(pekeris_env()...), 100.0);

julia> p = acoustic_field(sol, 1_000:100:10_000, 25.0, 0:5:100);

julia> size(p), eltype(p)   # 21 depths × 91 ranges
((21, 91), ComplexF64)

Kraken.broadband_field — Method
broadband_field(env, freqs, ranges, zs, zr; nmodes=typemax(Int), mode=:coherent, kwargs...)

Solve env at every frequency in freqs and evaluate the field at each, for pulse synthesis.

Returns a length(freqs) × length(zr) × length(ranges) array of complex pressure: frequency down the first axis, then the same depth × range layout acoustic_field returns. Extra kwargs go to kraken_jl.

A frequency that supports no trapped modes contributes zeros rather than an error, and f = 0 is zero by definition; both are normal at the low end of a band, and zero is the value the transform needs there.

Each frequency is an independent solve, so the loop is a map over freqs: turning it into a threaded map is the only change needed to parallelize it. That has not been done here; a parallel version of a wrong answer is still wrong, and task 7.4 is what confirms the serial one.

Arguments

  • env: the UnderwaterEnv to solve.
  • freqs: the frequencies (Hz). synthesize_pulse wants them evenly spaced.
  • ranges, zs, zr: as for acoustic_field.
  • nmodes, mode: as for acoustic_field, applied at every frequency.

Example

julia> env = UnderwaterEnv(pekeris_env()...);

julia> P = broadband_field(env, 10.0:10.0:200.0, 5_000.0, 36.0, 55.0);

julia> size(P)   # 20 frequencies × 1 depth × 1 range
(20, 1, 1)

Kraken.mode_amplitudes — Method
mode_amplitudes(sol::NormalModeSolution, z; nmodes=length(sol.kr))

Evaluate the mode shapes of sol at the depths z (metres, positive downwards).

Returns a length(z) × nmodes matrix (row per depth, column per mode) for a vector z, and a 1 × nmodes matrix for a scalar one. Interpolation is linear between mesh points; below the last mesh point the mode continues as φ(D)·exp(-γ(z - D)) into the bottom half-space, which is what KRAKEN's ReadOneMode does. Depths below a rigid or vacuum bottom are an error, as is a negative depth.

Arguments

  • sol: the solution from kraken_jl.
  • z: a depth or a vector of depths (m).
  • nmodes: evaluate only the first this many modes.

Example

julia> sol = kraken_jl(UnderwaterEnv(pekeris_env()...), 100.0);

julia> size(mode_amplitudes(sol, 0:10:100))   # 11 depths × 5 modes
(11, 5)

julia> size(mode_amplitudes(sol, 50.0; nmodes=2))
(1, 2)

Kraken.synthesize_pulse — Method
synthesize_pulse(P, freqs, times; spectrum=nothing, t_reduce=0)

Transform a complex spectrum P sampled at freqs into a real time series at times.

P is indexed by frequency along its first axis (a vector for one receiver, or the array broadband_field returns), and the result replaces that axis with one of length length(times). freqs must be evenly spaced; the spacing is the Δf of the transform.

Keyword arguments

  • spectrum: the source spectrum, as a vector over freqs or a function of frequency. The default is flat, which makes the result the band-limited impulse response of the waveguide.
  • t_reduce: subtracted from the travel time, so times are measured from t_reduce rather than from the source instant. Passing r / maximum(env.c.c) puts the earliest possible arrival at t = 0 and lets a short window hold a pulse that travelled a long way.

The phase convention is KRAKEN's, the same one acoustic_field documents: a mode carries e^{i(ωt - kᵣr)}, so this sums e^{+i2πft} and takes twice the real part, the positive-frequency half of a real signal's inverse transform.

Arguments

  • P: the spectrum, frequency along the first axis.
  • freqs: the evenly spaced frequencies (Hz) P is sampled at.
  • times: the times (s) to evaluate the signal at.

Example

julia> env = UnderwaterEnv(pekeris_env()...);

julia> freqs = 5.0:5.0:200.0;

julia> P = broadband_field(env, freqs, 5_000.0, 36.0, 55.0);

julia> t = 0:0.002:0.5;

julia> p = synthesize_pulse(P[:, 1, 1], freqs, t; t_reduce=5_000.0 / maximum(env.c.c));

julia> length(p) == length(t), eltype(p)
(true, Float64)
source
Kraken.transmission_loss — Method
transmission_loss(sol, ranges, zs, zr; nmodes=length(sol.kr), mode=:coherent)

Transmission loss in dB, -20log10|p|, for the field described by acoustic_field, with the same arguments, the same length(zr) × length(ranges) layout and the same conventions.

The reference is the pressure a point source of the same strength would produce at 1 m in free space, which is the normalization built into the field itself, so nothing further is subtracted here. Larger numbers mean a weaker signal.

Arguments

The same as acoustic_field's: sol, ranges (m), source depth zs (m), receiver depths zr (m), and the keywords nmodes and mode.

Example

julia> sol = kraken_jl(UnderwaterEnv(pekeris_env()...), 100.0);

julia> round.(transmission_loss(sol, 1_000:1_000:5_000, 25.0, 50.0); digits=1)
1×5 Matrix{Float64}:
 56.2  50.8  58.6  61.7  60.9

julia> smooth = transmission_loss(sol, 1_000:100:10_000, 25.0, 50.0; mode=:incoherent);

julia> size(smooth)
(1, 91)
source

Plotting

Available once a Makie backend is loaded (using CairoMakie or using GLMakie). The functions ending in ! draw into an existing axis and take plain arrays.

Kraken.plot_arrivals — Function
plot_arrivals(env::UnderwaterEnv, freqs, ranges, zs, zr, times;
              spectrum=nothing, reduction_speed=maximum(env.c.c), kwargs...)

Plot a record section: the broadband pulse received at depth zr at each of several ranges, one trace per range, offset by range. It shows how a pulse spreads out as the modes, travelling at different group speeds, separate.

Each trace is synthesized with broadband_field and synthesize_pulse, in reduced time t - r / reduction_speed, so an arrival travelling at reduction_speed lines up vertically and the whole section fits in one short window. Every trace is normalized to its own peak, so late, weak arrivals stay visible.

Requires a Makie backend: run using CairoMakie (or using GLMakie) to enable it.

Arguments

  • env: the UnderwaterEnv to solve.
  • freqs: evenly spaced frequencies (Hz), as synthesize_pulse requires.
  • ranges: the ranges (m) at which to draw a trace.
  • zs, zr: source and receiver depths (m).
  • times: the reduced times (s) to evaluate each trace at.
  • spectrum: the source spectrum, passed to synthesize_pulse. Flat by default.
  • reduction_speed: the speed (m/s) that sets the reduced time.
  • kwargs...: passed to broadband_field, and through it to kraken_jl.

Example

using CairoMakie
env = UnderwaterEnv(pekeris_env()...)
fig = plot_arrivals(env, 2.0:2.0:200.0, 2_000.0:2_000.0:10_000.0, 36.0, 55.0, 0:0.001:0.25)

Kraken.plot_dispersion — Function
plot_dispersion(env::UnderwaterEnv, freqs; nmodes=10, kwargs...)

Plot the phase speed ω/kᵣ of the first nmodes modes against frequency. Each mode appears at its cutoff frequency, entering at the bottom half-space speed, and falls towards the slowest sound speed in the water as frequency rises. Both limits are drawn as reference lines.

Solves env at every frequency in freqs; kwargs go to kraken_jl. Only real wavenumbers are drawn: for a lossy environment the phase speed uses Re(kᵣ).

Requires a Makie backend: run using CairoMakie (or using GLMakie) to enable it.

Arguments

  • env: the UnderwaterEnv to solve.
  • freqs: the frequencies (Hz).
  • nmodes: how many modes to draw, from the first.

Example

using CairoMakie
fig = plot_dispersion(UnderwaterEnv(pekeris_env()...), 5.0:1.0:150.0; nmodes=6)

Kraken.plot_tl — Function
plot_tl(sol::NormalModeSolution, ranges, zs, zr; mode=:coherent, nmodes=length(sol.kr),
        colorrange=nothing, colormap=Reverse(:viridis))

Plot transmission loss over a grid of ranges and receiver depths, as a heatmap with the surface at the top and a colorbar in dB. The source position is marked.

Requires a Makie backend: run using CairoMakie (or using GLMakie) to enable it.

Arguments

  • sol: the solution from kraken_jl.
  • ranges: the ranges (m). They are drawn in km.
  • zs: source depth (m).
  • zr: receiver depths (m).
  • mode, nmodes: passed to transmission_loss.
  • colorrange: the dB span of the color scale. The default runs from the 2nd percentile of the field to 50 dB above it, which keeps a deep null from washing out the rest.
  • colormap: any Makie colormap. The default makes loud (low TL) bright.

Example

using CairoMakie
sol = kraken_jl(UnderwaterEnv(munk_env()...), 50.0)
fig = plot_tl(sol, 1_000.0:250.0:100_000.0, 1000.0, 0.0:25.0:5000.0)
source
Kraken.plot_tl! — Function
plot_tl!(ax, ranges, zr, tl::AbstractMatrix; colorrange=nothing, colormap=Reverse(:viridis), kwargs...)

Draw a transmission-loss matrix into the Makie axis ax as a heatmap, with ranges in km along the horizontal axis. tl has one row per receiver depth in zr and one column per range in ranges, which is the layout transmission_loss returns. Non-finite values (the Inf of a pressure-release surface) are left blank. kwargs go to Makie.heatmap!. Returns the plot object, so a Colorbar can be attached to it.

Because it takes a plain matrix, it draws TL from any source with the same styling, and a difference of two TL matrices too (pass a diverging colormap and a symmetric colorrange).

Example

using CairoMakie
sol = kraken_jl(UnderwaterEnv(pekeris_env()...), 100.0)
r, z = 1_000.0:50.0:10_000.0, 0.0:1.0:100.0
fig = Figure()
ax = Axis(fig[1, 1]; yreversed=true)
hm = plot_tl!(ax, r, z, transmission_loss(sol, r, 36.0, z))
Colorbar(fig[1, 2], hm; label="TL (dB)")
source
Kraken.plot_tl_range — Function
plot_tl_range(sol::NormalModeSolution, ranges, zs, zr::Real; nmodes=length(sol.kr))

Plot transmission loss against range at a single receiver depth, coherent and incoherent together. The coherent curve shows the modal interference; the incoherent one is the mean level it oscillates about. TL increases downwards, as is conventional.

Requires a Makie backend: run using CairoMakie (or using GLMakie) to enable it.

Arguments

  • sol: the solution from kraken_jl.
  • ranges: the ranges (m), drawn in km.
  • zs, zr: source and receiver depths (m).
  • nmodes: passed to transmission_loss.

Example

using CairoMakie
sol = kraken_jl(UnderwaterEnv(pekeris_env()...), 100.0)
fig = plot_tl_range(sol, 100.0:10.0:10_000.0, 36.0, 55.0)
