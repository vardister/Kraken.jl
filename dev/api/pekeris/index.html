Pekeris closed form

Kraken.PekerisUnderwaterEnv — Type
PekerisUnderwaterEnv(c1, cb, ρ1, ρb, depth)

The Pekeris waveguide in closed form: an isovelocity water layer over a homogeneous fluid half-space. This is the separate, analytic solve path: find_kr on one of these solves the dispersion relation directly instead of going through the finite-difference machinery, which makes it the reference the general solver is checked against. It is lossless.

Arguments

  • c1, ρ1: water sound speed (m/s) and density (kg/m³).
  • cb, ρb: half-space sound speed and density. cb > c1 is required for trapped modes and asserted.
  • depth: water depth (m).

The same waveguide for the finite-difference solver is pekeris_env.

Example

julia> env = PekerisUnderwaterEnv(1500.0, 1600.0, 1000.0, 1500.0, 100.0);

julia> env.depth
100.0

Kraken.find_kr — Method
find_kr(env::PekerisUnderwaterEnv, freq; n_points=2_000, method=Roots.A42(), kwargs...)

The horizontal wavenumbers of the Pekeris waveguide at frequency freq (Hz), in descending order, from its dispersion relation tan(kz·D) + (ρb/ρ1)·kz/γ = 0.

The trapped band ω/cb < kr < ω/c1 is sampled at n_points points, every sign change from positive to negative is taken as a bracket, and each is refined with Roots.find_zero. The dispersion function also changes sign at the poles of tan, from negative to positive, which is why only one direction counts. Two modes closer together than the sampling step would be missed; n_points is what to raise if that ever happens.

Arguments

  • env: the PekerisUnderwaterEnv.
  • freq: frequency (Hz).
  • n_points: samples of the trapped band used to bracket the roots.
  • method: the Roots.jl method passed to find_zero.
  • kwargs...: passed to find_zero.

Returns an empty vector when no mode is trapped.

Example

The finite-difference solve of the same waveguide agrees to the digits shown:

julia> env = PekerisUnderwaterEnv(1500.0, 1600.0, 1000.0, 1500.0, 100.0);

julia> round.(find_kr(env, 100.0); digits=4)
5-element Vector{Float64}:
 0.4179
 0.415
 0.41
 0.4029
 0.3938

julia> round.(kraken_jl(UnderwaterEnv(pekeris_env()...), 100.0).kr; digits=4) == round.(find_kr(env, 100.0); digits=4)
true

Kraken.find_spans — Method
find_spans(func, x)

The consecutive pairs (x[i], x[i+1]) across which func goes from positive to negative, the brackets find_kr(::PekerisUnderwaterEnv, freq) refines. Returns a lazy generator of tuples, or an empty vector when there are none.

Arguments

  • func: a scalar function.
  • x: increasing sample points.

Example

julia> collect(find_spans(cos, 0:0.5:5))   # cos falls through zero at π/2 and rises at 3π/2
1-element Vector{Tuple{Float64, Float64}}:
 (1.5, 2.0)

Kraken.get_modal_function — Method
get_modal_function(env, krs, freq)

Build the Pekeris mode function Ψ(z, mode) for wavenumbers krs at frequency freq.

Returns a closure, so it can be evaluated at any depth: sinusoidal in the water column and exponentially decaying below the interface, normalized the same way as get_modal_function_values (which is the right call when you only need a fixed pair of depths).

Arguments

  • env: the PekerisUnderwaterEnv.
  • krs: its wavenumbers at freq, from find_kr(env, freq).
  • freq: frequency (Hz).

The closure takes a depth z (m, positive downwards) and a mode index.

Example

julia> env = PekerisUnderwaterEnv(1500.0, 1600.0, 1000.0, 1500.0, 100.0);

julia> krs = find_kr(env, 100.0);

julia> Ψ = get_modal_function(env, krs, 100.0);

julia> Ψ(50.0, 2) == last(get_modal_function_values(env, krs, 100.0, 0.0, 50.0))[2]
true
source
Kraken.get_modal_function_values — Method
get_modal_function_values(env, krs, freq, zr, zs)

Evaluate the normalized Pekeris mode functions at a receiver depth and a source depth.

Returns (modes_zr, modes_zs), two vectors with one value per wavenumber in krs. Below depth the modes decay exponentially into the half-space.

Arguments

  • env: the PekerisUnderwaterEnv.
  • krs: its wavenumbers at freq, from find_kr(env, freq).
  • freq: frequency (Hz).
  • zr, zs: receiver and source depths (m, positive downwards).

Example

julia> env = PekerisUnderwaterEnv(1500.0, 1600.0, 1000.0, 1500.0, 100.0);

julia> krs = find_kr(env, 100.0);

julia> ψr, ψs = get_modal_function_values(env, krs, 100.0, 0.0, 50.0);

julia> all(iszero, ψr)   # every mode vanishes at the pressure-release surface
true

Kraken.pressure_f — Method
pressure_f(env::PekerisUnderwaterEnv, krs, freq, r, zs, zr; t0=0.1, max_modes=Inf)

The complex pressure of the Pekeris waveguide at one frequency, range and depth pair, as a normal mode sum. Returns zero at freq = 0 or when there are no modes.

The result carries an extra phase exp(2πi·freq·(r/min(c1, cb) - t0)), which shifts the arrival to t0 seconds into a time window when the spectrum is inverse-transformed. At a single frequency it changes the phase and leaves abs alone.

Arguments

  • env: the PekerisUnderwaterEnv.
  • krs: its wavenumbers at freq, from find_kr(env, freq).
  • freq: frequency (Hz).
  • r: range (m).
  • zs, zr: source and receiver depths (m, positive downwards).
  • t0: where in the time window the arrival lands (s).
  • max_modes: sum only the first this many modes.

Example

julia> env = PekerisUnderwaterEnv(1500.0, 1600.0, 1000.0, 1500.0, 100.0);

julia> krs = find_kr(env, 100.0);

julia> p = pressure_f(env, krs, 100.0, 5_000.0, 25.0, 50.0);

julia> p isa Complex, abs(pressure_f(env, krs, 100.0, 5_000.0, 25.0, 50.0; t0=0.0)) ≈ abs(p)
(true, true)
